# BizTalk to Azure Migration Lab

A hands-on lab for learning and practicing the migration of a legacy BizTalk integration solution to Azure Integration Services.

## Goal

The purpose of this project is to experience the complete migration journey:

Legacy BizTalk
→ Discovery
→ Analysis
→ Migration Planning
→ Azure Architecture
→ Implementation
→ Validation
→ Deployment
