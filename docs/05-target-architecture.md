# Target Architecture

No Azure target architecture has been finalized. Azure services will be selected only after evaluating:

- Legacy discovery findings
- Integration patterns
- Workload characteristics
- Message sizes
- Synchronous and asynchronous behavior
- Security requirements
- Reliability requirements
- Cost requirements

## Candidate Azure Integration Services

- Azure Logic Apps
- Azure Service Bus
- Azure API Management
- Azure Event Grid
- Azure Functions
- Azure Key Vault
- Managed Identities
- Application Insights

These are candidate services, not final architecture decisions.
